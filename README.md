# 📂 Almacén de Recursos - El Rincón de Carlos

Este repositorio sirve como infraestructura externa para mi blog [El Rincón de Carlos](https://elrincondecarlos1977.blogspot.com/).

### 📋 Contenido
Aquí alojo archivos que la plataforma Blogger no permite gestionar directamente:
* **Audios (MP3):** Bandas sonoras y archivos de audio para las entradas del blog.
* **Documentación (PDF):** Información técnica y archivos descargables para los lectores.
* **Otros recursos:** Archivos de soporte para el diseño y funcionamiento del sitio.

### ⚙️ Uso Técnico
Los archivos aquí alojados se vinculan mediante enlaces directos a las entradas del blog, asegurando que el contenido esté siempre disponible y organizado.
